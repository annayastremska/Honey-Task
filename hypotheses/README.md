# Перевірка гіпотез

Одна тема — один файл `tN-тема.md`, де `tN` — номер завдання.
Протокол (розділи «Правила», «Базове припущення», «Гіпотези», «Оцінка») пишеться і комітиться до прогону й після нього не змінюється.
«Результати» і «Вердикти» дописуються після прогону.

## Структура файлу

1. **Питання завдання** — дослівно, одним рядком.
2. **Правила** — які стандарти аналізу застосовано, з джерелом.
3. **Дані** — файл, колонки, дні; що виключено і чому.
4. **Базове припущення** — на чому стоїть вся оцінка і які є альтернативні пояснення.
5. **Гіпотези** — для кожної: твердження, альтернатива, метод, межа, критерій.
6. **Оцінка** — як рахуємо відповідь і як перевіряємо її стійкість.
7. **Результати** — таблиці з кількістю точок.
8. **Вердикти** — дослівно за критеріями.
9. **Висновок** — відповідь на питання завдання.
10. **Відкриті питання** — як питання, не як факт.
